Webhooks

Lumen sends an HTTP POST to your endpoint when an event occurs.

Register an endpoint

Use the CLI:

lumen webhook add --url https://example.org/hook --event invoice.paid

Endpoints must answer within 5 seconds or the delivery is retried.

Deliveries are signed with your endpoint secret.

Payload

{
  "event": "invoice.paid",
  "id": "evt_123",
  "data": { "amount": 4200 }
}
  • The id is unique per delivery.
  • Order of delivery is not guaranteed.
