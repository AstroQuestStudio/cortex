API Reference

Authentication

Authenticate your requests with an API key.

Send your key in the Authorization header of every request.

Creating a key

Open Settings then API keys and click Create.

Keep your key secret. Anyone with the key can act on your behalf.

Making a request

curl https://api.hexa.example/v1/me \
  -H "Authorization: Bearer $HEXA_KEY"
const res = await fetch("https://api.hexa.example/v1/me", {
  headers: { Authorization: `Bearer ${process.env.HEXA_KEY}` },
});

Keys never expire, but you can rotate them at any time.

Response codes

CodeMeaning
401Missing or invalid key
403Key lacks the required scope
