Expand description

Parses a configuration string into a typed Config.

The input may be anything that implements AsRef<str>. Comments starting with # are ignored.

§Errors

Returns ParseError::Syntax if the input is not valid, with the line and column of the first problem.

§Examples

use tomlish::{parse_config, Options};

let cfg = parse_config("name = \"demo\"", &Options::default()).unwrap();
assert_eq!(cfg.get_str("name"), Some("demo"));
fn main() {
let bad = tomlish::parse_config("= 1", &Default::default());
assert!(bad.is_err());
}
