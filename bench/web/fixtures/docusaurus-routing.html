Routing

FluxRouter maps incoming URLs to handlers. Register routes with router.add() and match them with router.resolve().

Defining routes​

A route is a pattern plus a handler. The simplest router looks like this:

src/router.ts
import { Router } from 'fluxrouter';

const router = new Router({ strict: true });
router.add('/users/:id', (ctx) => ctx.json({ id: ctx.params.id }));
warning

Routes are matched in declaration order. Declare specific routes before catch-all patterns.

Path params​

Segments starting with a colon are captured into ctx.params.

Optional params​

Add a question mark to make a segment optional:

router.add('/blog/:slug?', showBlog);
