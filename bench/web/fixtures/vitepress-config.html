Configuration ​

Quillbase reads its settings from a quillbase.config.ts file in the project root. All fields are optional.

Files ​

Create the file with the helper defineConfig to get type checking:

ts
import { defineConfig } from 'quillbase'

export default defineConfig({
  outDir: 'dist',
  cleanUrls: true,
})

WARNING

Changing outDir after the first build leaves stale files behind. Delete the old directory by hand.

TIP

The config file is reloaded automatically in dev mode.

Environment variables ​

Variables prefixed with QB_ are exposed to the config:

sh
export QB_TOKEN=abc123
powershell
$env:QB_TOKEN = "abc123"

Reserved names ​

  • QB_HOME: the data directory
  • QB_LOG: the log level, one of debug, info, warn
Why a config file?

Code-based configuration lets editors complete option names.
