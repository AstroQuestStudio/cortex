Data Fetching

Pixelkit components can load data on the server or in the browser.

Loading data

Call useQuery inside a component:

const { data } = useQuery('/api/items');
if (!data) return <Spinner />;
⚠️
Queries run twice in development because of React strict mode.
ℹ️
Results are cached for 30 seconds by default.

Error states

Check error on the returned object.
