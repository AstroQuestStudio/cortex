Installation¶

Squid ships as a single static binary. Pick the method that fits your platform.

From a package manager¶

 pip install squid-cli==3.4.0

conda install -c squid squid-cli=3.4.0

Warning

Version 3.3 and older are not supported on Python 3.12.

From source¶

Clone the repository and build with cargo:

git clone https://example.net/squid.git
cd squid
cargo build --release

Note

A recent Rust toolchain (1.75 or newer) is required.

Custom prefix

Pass --prefix to the install script to change the target directory.
