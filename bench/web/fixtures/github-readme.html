Gearbox

A tiny task runner for shell-heavy projects. No daemon, no config language.

Install

cargo install gearbox --locked

Usage

Create a Gearfile and declare tasks:

[task.build]
run = "cargo build"
deps = ["fmt"]

[task.fmt]
run = "cargo fmt --check"

Warning

Tasks run with your full environment. Never run a Gearfile from an untrusted source.

Flags

  • --dry-run: print the commands without running them
  • --jobs N: run up to N tasks in parallel
    • defaults to the number of cores
