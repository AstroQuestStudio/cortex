Developer Interface¶

This part of the documentation covers all the interfaces of Fetchly. For parts where Fetchly depends on external libraries, we document the most important right here.

Main Interface¶

All of Fetchly' functionality can be accessed by these 2 methods.

fetchly.get(url, params=None, **kwargs)[source]¶

Sends a GET request.

Parameters:

  • url – URL for the new Request object.

  • params – (optional) Dictionary of query parameters.

Returns:

Response object

Warning

Without timeout a request can hang forever.

New in version 2.28: The params argument accepts a list of tuples.

>>> import fetchly
>>> r = fetchly.get('https://example.org', params={'q': 1})
class fetchly.Session¶

A Fetchly session. Provides cookie persistence and connection pooling.

close()¶

Closes all adapters and as such the session.
